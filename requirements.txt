# Sector Analyst Agent — pinned dependencies
#
# Two cross-package constraints drive these pins; read them before changing anything:
#
#   1. MCP major version. langchain-mcp-adapters 0.3.2 caps `mcp<2.0.0`, while
#      fastmcp>=4.0.0 requires `mcp>=2.0.0`. The two are mutually unsatisfiable, and
#      pip does NOT fail loudly on it — left unpinned it resolves to
#      fastmcp 4.0.2 + mcp 2.1.1 + langchain-mcp-adapters 0.3.1, silently reaching back
#      to the one adapter release whose `mcp>=1.24.0` pin is unbounded. 0.3.2 added the
#      `<2.0.0` cap precisely to disavow that combination. So the server stays on the
#      last mcp-1.x fastmcp line and the client stays at 0.3.2.
#
#   2. LangChain v1 tree. langgraph 1.2.11 needs langchain-core>=1.4.7,
#      langchain-google-genai 4.4.0 needs >=1.6.1, langchain-mcp-adapters needs >=1.3.3.
#      One consistent langchain-core 1.x satisfies all three; do not mix in a 0.x package.
#
# Resolved and verified against PyPI on 2026-09-04.
